Customer Churn Prediction Using Machine Learning

📌 Project Overview

Customer Churn Prediction is a Machine Learning project that predicts whether a customer is likely to leave a company’s products or services.

Customer churn occurs when customers stop using a company’s services or switch to another company. This project analyzes customer information and uses Machine Learning algorithms to identify customers who may leave.

The main aim is to help companies understand customer behaviour, improve customer satisfaction, and reduce customer loss.

🎯 Objectives

* Predict whether a customer will leave or stay.
* Analyze customer behaviour and usage patterns.
* Identify customers who are at risk of leaving.
* Apply Machine Learning algorithms for prediction.
* Help businesses improve customer retention.

🛠️ Technologies Used

* Python – Programming language
* Pandas – Data manipulation and analysis
* NumPy – Numerical operations
* Matplotlib – Data visualization
* Seaborn – Statistical data visualization
* Scikit-learn – Machine Learning model development
* Streamlit – Web application interface
* Jupyter Notebook – Model development and testing

📂 Dataset

This project uses the IBM Telco Customer Churn dataset.

The dataset contains customer information such as:

* Customer ID
* Gender
* Senior Citizen
* Tenure
* Monthly Charges
* Total Charges
* Contract Type
* Internet Service
* Payment Method
* Churn Status

Dataset Link: https://www.kaggle.com/datasets/blastchar/telco-customer-churn

⚙️ Project Workflow

1. Data Collection: Collect customer information from the dataset.
2. Data Preprocessing: Clean the dataset and handle missing values.
3. Exploratory Data Analysis: Analyze customer behaviour using graphs and charts.
4. Model Training: Train Machine Learning algorithms using customer data.
5. Model Evaluation: Evaluate model performance using suitable evaluation metrics.
6. Prediction: Predict whether a customer is likely to leave or stay.
7. Visualization: Display prediction results through a user interface.

🤖 Machine Learning Algorithms

The following algorithms can be used:

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)

📊 Expected Output

The system predicts two possible outcomes:

* Churn = Yes: The customer is likely to leave the company.
* Churn = No: The customer is likely to continue using the company’s services.

The application can also display customer information, prediction probabilities, and visual analytics.
